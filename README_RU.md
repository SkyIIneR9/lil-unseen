# LiL Unseen

Русский · [English](README.md)

Инструмент для поиска **непрочитанных реплик Lessons in Love**, включая пропущенные развилки внутри уже посещённых сцен. Позволяет изучать локальный отчёт, переходить к репликам с подготовкой изображения и музыки, а затем пользоваться кнопкой **«Следующий фрагмент»** прямо в игре.

Неофициальный фанатский проект. Здесь только код инструмента и выдуманные тестовые данные. Нужна собственная установленная игра; сценарии, реплики, изображения, сохранения и код URM не распространяются. Сам URM для работы не требуется.

## Возможности

- Сопоставление ID диалогов с накопленной историей чтения в `persistent`.
- Объединение соседних непрочитанных реплик в фрагменты, поиск по тексту, персонажу, лейблу, ID и условиям.
- Фильтры частично прочитанных сцен, посещённых лейблов, файлов и явных веток `bonus == False`.
- Копирование команд перехода: с подготовкой кадра, точно к реплике или к началу сцены.
- Кнопки «Назад», «Следующий фрагмент», «Скрыть» внутри игры.
- Локальные HTML, JSON и TSV без сервера, сетевого подключения, аккаунта и дополнительных пакетов Python.
- Русский и английский интерфейсы отчёта и игровой панели. Текст новеллы остаётся на языке установленных сценариев.

## Совместимость

Проверено на Windows, **Ren’Py 8.2.3** и одной русской сборке Lessons in Love: папка называется 0.60.0, а сценарии объявляют версию 0.61.0. Оригинальная английская сборка, другие версии, другие моды, macOS и Linux пока не проверены. Это первый экспериментальный релиз, а не универсальный мод для любого Ren’Py.

Для экспорта нужен установленный **Python 3.10+**. Игровой помощник использует Python из комплекта игры. Node.js нужен только разработчикам для тестирования отчёта.

Поддерживаются архивы RPA 2/3 и отдельные скомпилированные сценарии; отдельные файлы имеют приоритет. Переводы, выбираемые отдельным языком Ren’Py, пока не поддерживаются: при языке не `None` в persistent экспорт остановится с пояснением. Проверенная русская сборка содержит перевод прямо в базовых сценариях.

## Установка

1. Скачай ZIP репозитория через **Code → Download ZIP** и распакуй.
2. Закрой игру. Скопируй папки **`game`** и **`research_unseen`** из архива в корень игры, рядом с её `.exe`. Объедини папки; помощник добавляет собственный файл.
3. Один раз запусти игру для компиляции помощника и нормально выйди. Помощник также включает консоль Ren’Py.
4. Запусти `research_unseen/refresh_report.cmd`, выбери **R** для русского или **E** для английского и дождись открытия отчёта.

Должна получиться такая структура:

```text
LessonsInLove/
  LessonsInLove….exe
  game/
    0unseen_research.rpy
    ...остальные файлы игры...
  research_unseen/
    export_unseen.py
    refresh_report.cmd
    ...файлы инструмента...
```

Если нужен **только отчёт**, файл `game/0unseen_research.rpy` можно не устанавливать. Для чтения HTML мод внутри игры не нужен.

Ручной экспорт из корня игры:

```powershell
python research_unseen/export_unseen.py --ui-language ru
```

Можно указать другую папку игры или резервную копию persistent:

```powershell
python research_unseen/export_unseen.py --root "D:\Games\LessonsInLove" --persistent "D:\Backups\persistent" --ui-language ru
```

Игровой помощник всегда читает `<корень игры>/research_unseen/output/navigation.json`. Если запускаешь экспортёр из отдельной папки проекта, добавь `--output` с этим путём. Отчёт в произвольной другой папке подходит для чтения без игровой навигации.

## Как пользоваться

1. Открой `research_unseen/output/unseen.html` в браузере. В нём спойлеры. Чтение страницы не меняет прогресс игры.
2. В игре загрузи **отдельный исследовательский сейв** и остановись на обычной реплике.
3. В карточке отчёта нажми **«С подготовкой кадра»**, открой консоль через **Shift+O** (латинская O), вставь команду и нажми Enter. Если автоматическое копирование недоступно, команда выделится для Ctrl+C.
4. В игре пользуйся кнопкой **«Следующий фрагмент»**. «Назад» позволяет повторно открыть прочитанные фрагменты. «Скрыть» убирает панель; следующий подготовленный переход вернёт её.
5. После исследования нормально закрой игру и снова запусти экспортёр.

Панель идёт по всему отчёту в порядке файл/лейбл/строка, исключает явные ветки `bonus == False` и пропускает уже прочитанные ID по живому persistent. **Фильтры в браузере не управляют этой очередью.** Это не хронологический порядок событий.

**«Точный переход»** не подготавливает оформление. **«К лейблу»** начинает сцену с её обычными проверками. Эти варианты не подбирают сюжетные переменные автоматически.

## Что восстанавливается при переходе

Подготовка воспроизводит определимые команды `scene`, `show`, `hide` и музыки. Музыка начинается заново, старые звуковые эффекты и голоса прекращаются. Если фон неизвестен, основной слой очищается; неизвестная музыка заменяется тишиной. Динамические изображения используют переменные текущего сейва. Камеры, пользовательские экраны и другие слои могут сохранить старое состояние.

Подготовка не выполняет предшествующие сюжетные присваивания и не решает условия. **После перехода обычный код игры продолжает выполняться**, включая изменения отношений и другие последствия. Прямой переход может показать служебную или недостижимую реплику. Используй отдельный сейв; его последующая загрузка не отменит накопленные отметки прочитанного в persistent.

Непрочитанный ID означает отсутствие отметки исполнения в этом persistent, а не доказательство того, что игрок никогда не видел текст или что ветка достижима обычным путём. Версии, моды и потеря persistent влияют на результат. Инструмент не загружает и не объединяет все слоты сохранений. Условия в карточке — подсказка для исследования, а не полный маршрут прохождения.

## Если что-то не работает

| Проблема | Что сделать |
| --- | --- |
| Python не найден или открывается Microsoft Store | Установить Python 3.10+ с добавлением в PATH, затем снова открыть запускатор. |
| Исходник новее скомпилированного файла | Запустить игру, нормально выйти и повторить экспорт. |
| Persistent не найден | Поиграть и нормально выйти либо указать `--persistent`. На Windows проверяются AppData и локальные сохранения. |
| `NameError: unseen_research_jump` | Проверить обе папки инструмента и полностью перезапустить игру. |
| Navigation report mismatch | Закрыть игру и заново создать отчёт из этой же установки. Разница имён архивных `.rpyc` уже учтена. |
| Shift+O не открывает консоль | Проверить компиляцию помощника и перезапустить игру. Другой мод может переопределять настройку консоли. |
| Неверный или пустой фон, нет музыки | Часть контекста не восстанавливается. Попробовать переход к лейблу или более подходящий сейв. |
| Incomplete/ambiguous extraction или unsupported language | Эта сборка пока не поддерживается. Сообщить версию и ошибку, не прикладывая сценарии и сохранения. |

Для удаления помощника закрой игру и удали **оба** файла `game/0unseen_research.rpy` и `game/0unseen_research.rpyc`. Затем можно удалить папку инструмента. Не удаляй папки целиком, если в них находятся другие нужные файлы.

## Личные данные и распространение

Созданные отчёты содержат текст игры, спойлеры, историю прочитанного и локальные пути. Папка `research_unseen/output/` должна оставаться у тебя. Не публикуй отчёты, сохранения, persistent, игровые архивы, декомпилированные сценарии и извлечённый код URM. `.gitignore` исключает эти материалы, а упаковщик релиза использует явный список файлов инструмента.

Офлайн-чтение заменяет поддерживаемые объекты Ren’Py из pickle инертными структурами, не импортирует движок и не выполняет игровой Python. Это не песочница для произвольных вредоносных файлов: используй данные собственной доверенной установки.

## Разработка

```powershell
python -m unittest discover -s research_unseen -p "test_*.py"
node tests/verify_viewer.cjs
python tools/build_release.py
```

Тесты используют выдуманные данные и не требуют файлов игры. CI запускает их на Windows и Linux. Интеграция с Ren’Py 8.2.3 также проверена локально; это не означает проверку каждой сцены. Архив для распространения создаётся в `dist/`.
