# Contributing / Участие

Issues and pull requests in English or Russian are welcome.

For a bug, include the game version, Ren’Py version, OS, tool revision, chosen UI language, the action you took, and the error message. Remove your username and private paths. Include a dialogue ID if relevant, but do not attach game dialogue, scripts, archives, images, saves, persistent files, or complete generated reports. Small invented examples are best for tests.

The exporter must not execute game Python or write saves/persistent. Navigation must validate every target before changing presentation or popping the console frame. Tests must run without game assets.

---

Можно писать issues и pull requests на русском или английском.

Для ошибки укажи версию игры, Ren’Py, ОС, ревизию инструмента, язык интерфейса, действие и текст ошибки. Убери имя пользователя и личные пути. При необходимости укажи ID реплики, но не прикладывай текст игры, сценарии, архивы, изображения, сохранения, persistent или полные отчёты. Для тестов подходят небольшие выдуманные примеры.

Экспортёр не должен выполнять игровой Python или записывать сохранения/persistent. Навигатор проверяет все цели до изменения оформления и снятия кадра консоли. Тестам не должны требоваться игровые материалы.
