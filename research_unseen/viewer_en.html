Unseen dialogue

A local Ren’Py snapshot. Contains spoilers. Reading does not change game progress.

How to use

Install the helper and restart the game. Load a separate experimental save and pause during normal dialogue.

Consecutive unread dialogue in one straight branch is grouped into fragments. Read dialogue and branching boundaries split fragments. Jump once, then continue with normal clicks.

Click Prepare scene & jump, open the game console with Shift+O (letter O), paste and press Enter. If clipboard access fails, use Ctrl+C on the selected command.

The in-game Next fragment panel follows the entire report, excluding bonus == False branches, and skips read IDs using live persistent state. Browser filters do not affect this queue. Previous can revisit read fragments. Hide removes the panel; another prepared jump brings it back.

Preparation does not execute preceding story assignments or choose variables. Music restarts; old sound effects stop. Unknown backgrounds become blank; unknown music becomes silence. Cameras and custom screens may retain state. After landing, normal game code and its consequences run.

Search returns whole fragments. Conditions show surrounding checks, not a complete route. Scene start runs the label with its normal checks; Exact jump skips media preparation.

Dialogue shown in the game is marked read. Quit normally and run refresh_report.cmd to refresh. If unseen_research_jump raises NameError, check installation and restart the game.
