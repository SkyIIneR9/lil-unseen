# Roadmap / Планы

These are proposals, not implemented features. / Это предложения, а не готовые функции.

1. **Filtered game queue / Очередь по фильтрам.** Export the current browser selection for the in-game panel, with a visible fragment counter. / Передавать выборку браузера игровой панели и показывать номер фрагмента.
2. **Bookmarks / Закладки.** Keep a private list of interesting IDs and notes, separate from read history. / Хранить личные ID и заметки отдельно от прогресса чтения.
3. **Condition inspector / Просмотр условий.** Show relevant current variables without modifying them; distinguish text candidates from confirmed reachable paths. / Показывать текущие значения нужных переменных без изменения и отличать кандидатов от доказанно достижимых веток.
4. **Compatibility fixtures / Проверка сборок.** Validate original English releases and selected translation languages using independently created test cases. / Проверить английские версии и отдельные языки перевода на самостоятельно созданных тестах.
5. **Report comparison / Сравнение отчётов.** Show which IDs were read or changed since the previous snapshot. / Показывать прочитанные и изменившиеся ID между снимками.

Automatic story-variable editing needs separate design: conditions can trigger irreversible changes within a save. It is not included in this release. / Автоматическое изменение сюжетных переменных требует отдельного проектирования: условия могут запускать необратимые изменения внутри сейва. В этом релизе такой функции нет.
